# Robôs de Trading

Estratégias automatizadas (robôs) em NTSL para a plataforma Profit.

> Ainda não iniciado. Reservado para uma fase posterior do projeto, após indicadores e regras de coloração estarem estabelecidos.

Quando iniciado, cada robô deve conter no cabeçalho:

- **Nome**
- **Objetivo/lógica da estratégia**
- **Parâmetros** (inputs, stops, position sizing)
- **Ativos/timeframes testados**
- **Resultados de backtest/forward test** (referenciar em `docs/`)
- **Data da última alteração**

## Convenção de nomes

`nome_do_robo.ntsl` (snake_case, sem espaços ou acentos).
