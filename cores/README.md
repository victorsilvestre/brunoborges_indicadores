# Regras de Coloração

Regras de coloração (color rules) em NTSL para a plataforma Profit.

Cada regra deve ficar em seu próprio arquivo `.ntsl`, com um cabeçalho de comentário no topo contendo:

- **Nome**
- **Objetivo** (que condição/sinal a coloração representa)
- **Parâmetros**
- **Ativos/timeframes testados**
- **Data da última alteração**

## Convenção de nomes

`nome_da_regra.ntsl` (snake_case, sem espaços ou acentos).
