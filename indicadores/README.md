# Indicadores

Indicadores em NTSL para a plataforma Profit (Nelogica).

Cada indicador deve ficar em seu próprio arquivo `.ntsl`, com um cabeçalho de comentário no topo contendo:

- **Nome**
- **Objetivo** (o que mede/mostra)
- **Parâmetros** (inputs configuráveis e seus valores padrão)
- **Ativos/timeframes testados**
- **Data da última alteração**

## Convenção de nomes

`nome_do_indicador.ntsl` (snake_case, sem espaços ou acentos).
